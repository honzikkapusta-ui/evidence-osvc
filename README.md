# Evidence příjmů a výdajů pro OSVČ

Jednoduchý přehled příjmů a výdajů pro vedlejší i hlavní živnost. Bez registrace, bez účtu.

- **Aplikace v prohlížeči:** `index.html` (otevři dvojklikem nebo přes GitHub Pages). Data zůstávají jen v tvém prohlížeči, dají se zálohovat do souboru.
- **Excel verze:** `evidence-osvc.xlsx` (funguje v Excelu, LibreOffice i Google Tabulkách).

Umí příjmy a výdaje po měsících, graf, roční součty a srovnání zisku při paušálních výdajích a při skutečných.

## Co to NENÍ
Není to účetní program ani daňové poradenství. Nepočítá daň, zdravotní ani sociální pojištění a nepodává přiznání. Procento paušálních výdajů a limity si ověř na financnisprava.gov.cz.
